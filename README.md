📝 Todo List Desktop App (Python + CustomTkinter)

A modern desktop Todo List application built with Python and CustomTkinter.
This project started as a CLI app and evolved into a full graphical user interface (GUI) application.

🚀 Features
➕ Add new todos
❌ Delete todos
✏️ Inline edit todos (no popup window)
☑️ Mark todos as done / undone
📉 Done tasks automatically move to bottom
🔼🔽 Reorder todos (move up & down)
⌨️ Press Enter to quickly add tasks
🎨 Modern dark-themed UI using CustomTkinter
📂 Persistent storage using text file (todo.txt)
📱 Responsive layout (supports window resizing)
🖥️ Preview

A clean, modern desktop interface for managing daily tasks efficiently.

🛠️ Technologies Used
Python 3
CustomTkinter (modern Tkinter UI framework)
File Handling (TXT-based persistence)
